A Node 22 program that writes one line to /output/entry.txt — a hilariously useless superpower, 91 characters: instant healing, but only paper cuts, only my own, and only on Tuesdays.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
